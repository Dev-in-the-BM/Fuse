# Connection screen messages

The connection screen rotates through the messages in the current phase while
device detection is running. Messages are grouped by the connection step where
they appear. The failure message is shown as guidance and does not rotate.

## Connection failure

Shown as guidance when the connection fails; this message does not rotate:

> Could not initialize the device. Check USB/udev permissions, power it off, select bootrom or preloader mode, and review Logs.
